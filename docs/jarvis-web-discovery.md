# Mission-led public-web donor discovery

Jarvis → Leads & outreach now has Corporate and Individual category filters and a Find new prospects research panel. Corporate includes companies and corporate foundations; Individual targets publicly documented adult philanthropists, not wealth inference or lists of private people.

United Way search defaults are grounded in https://uwmidsouth.org/about/: poverty reduction and economic/social mobility; education, financial stability and health; Crittenden AR; DeSoto/Tate/Tunica MS; Fayette/Lauderdale/Shelby/Tipton TN. Staff can change the mission, public source URL, focus areas, geography, public source hints and exclusions. The most recent criteria are retained per user in the existing audit log. Defaults for other organizations require entry rather than inventing their mission.

A same-origin authenticated POST to /api/jarvis/discover checks fundraiser role, validates criteria, reserves a per-user/category two-minute cooldown, then uses the existing Anthropic connection and model. Live web research is capped at three provider searches per request and five candidate hypotheses. It prefers primary corporate giving pages, foundation/nonprofit reports, public donor recognition, chamber directories, and philanthropy announcements. Model/search usage carries ordinary provider charges; the UI states this before execution. No new external credentials or subscription is created.

No CRM names, gift histories, emails, or relationship notes are sent to the model. Only public mission criteria and the organization name are used. CRM and saved-lead name checks run locally inside the application before creating new records. Same-name matches are conservatively skipped as possible duplicates rather than merging identities.

A research pass returns real provider citations. The extraction pass can select indexes only from those citations. URL, title, and up-to-150-character excerpts are copied from provider responses, not generated by extraction. Unknown URLs/indexes and malformed responses fail closed. Claims about fit, geography, and suggested approach remain model interpretations requiring staff review; citations do not guarantee that the full interpretation is correct. Searches without usable citations or unfinished research create no leads. Public source hints are research data, not instructions or server-side URLs to fetch. No arbitrary server fetch or model write tool is exposed.

Saved web leads start at Researching with plausible fit and unknown relationship, capacity and timing. Contact fields remain empty; no private or guessed contact data is generated. Proposed outreach includes mandatory verification/personalization placeholders. The evidence panel displays the research date, focus connection, geographic rationale, proposed outreach angle, source links and excerpts. Existing lead scoring and staff approval remain in effect. Client edits cannot replace server-set provenance. No automatic sending, scheduled searches, or private/licensed database scraping is enabled.

Existing CRM-derived records retain their pipeline workflow. Older records without category are classified from linked donor type in the server-rendered list. Staff can correct the category. Older unlinked records fall under Individual until explicitly categorized. Category filters span the full saved list; sorting remains page-local.

Validation: existing six lead tests plus six discovery tests cover citation trust boundaries, URL safety, limits, mission defaults, categories, approval reset, extraction shape and name normalization. Compile/type checks run in Vercel. Live provider web-search permission and actual source quality must be checked through a signed-in pilot search after release. API failures return an actionable message without inventing results.
